# Security

Security reports should be handled privately before public disclosure.

## Reporting a Vulnerability

If you believe you found a vulnerability in Gleip, do not open a public issue. Send a private report to the maintainers with:

- Affected package or component.
- Steps to reproduce.
- Expected and actual impact.
- Any known workaround.

The project will acknowledge valid reports, investigate scope, prepare a fix, and coordinate disclosure when appropriate.
