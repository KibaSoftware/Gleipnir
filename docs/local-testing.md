# Local Testing

Use this workflow to run the Gleip CLI from the repository without publishing it to npm.

```sh
pnpm install
pnpm gleip --help
```

Create a temporary target repository:

```sh
mkdir -p /tmp/gleip-test
cd /tmp/gleip-test
git init
```

Run Gleip from this repository against the temporary target:

```sh
cd /path/to/Gleip
pnpm gleip --cwd /tmp/gleip-test init --all-agents
pnpm gleip --cwd /tmp/gleip-test init --all-agents
pnpm gleip --cwd /tmp/gleip-test preflight "Add CSV export to users table"
pnpm gleip --cwd /tmp/gleip-test brief
pnpm gleip --cwd /tmp/gleip-test status
pnpm gleip --cwd /tmp/gleip-test doctor
pnpm gleip --cwd /tmp/gleip-test stop
```

Inspect the generated files:

```sh
ls -la /tmp/gleip-test
ls -la /tmp/gleip-test/.gleip
cat /tmp/gleip-test/AGENTS.md
cat /tmp/gleip-test/CLAUDE.md
cat /tmp/gleip-test/.cursor/rules/gleip.mdc
cat /tmp/gleip-test/.gleip/brief.md
cat /tmp/gleip-test/.gleip/status.md
```

Expected results:

- `.gleip.yml` exists.
- `GLEIP.md` exists.
- `.gleip/` exists.
- `AGENTS.md` contains exactly one Gleip-managed section.
- `CLAUDE.md` contains exactly one Gleip-managed section.
- `.cursor/rules/gleip.mdc` contains exactly one Gleip-managed section.
- Re-running `init` does not duplicate the section.
- `preflight` creates `session.json`, `brief.md`, `scope-budget.json`, and `status.md`.

## Dogfooding This Repository

Gleip is used in this repository during local development. Commit the repo-level Gleip policy and documentation files:

- `.gleip.yml`
- `GLEIP.md`
- `AGENTS.md`

Do not commit local session state from `.gleip/`. These files are generated by local commands and are ignored:

- `.gleip/session.json`
- `.gleip/brief.md`
- `.gleip/scope-budget.json`
- `.gleip/status.md`
- `.gleip/baseline.json`
- `.gleip/state.json`

To reset a local Gleip session:

```sh
gleip stop
rm -rf .gleip
```

After large working tree changes, start from a fresh session:

```sh
gleip stop
rm -rf .gleip
gleip init --all-agents
gleip preflight "<task>"
```
